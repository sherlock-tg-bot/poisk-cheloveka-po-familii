# Безопасное и законное использование

Этот репозиторий посвящён поиску человека по фамилии и работе только с открытыми данными. Любая найденная информация может быть неполной, устаревшей или относиться к однофамильцу.

- Используйте поиск для законной цели и собирайте минимум необходимых сведений.
- Уважайте согласие и частную жизнь; не пытайтесь получить закрытые данные, адреса, телефоны, документы или доступ к аккаунтам в обход ограничений.
- Не применяйте результаты для преследования, доксинга, шантажа, дискриминации, мошенничества или навязчивых контактов.
- Не считайте совпадение фамилии доказательством личности. Проверяйте важные сведения у первоисточника или самого человека.
- Не вводите пароли, коды подтверждения, банковские реквизиты и другие секреты в сторонние формы.

Telegram-инструмент из README — лишь навигация по публичным упоминаниям. Он не заменяет согласие, официальную идентификацию и правовую процедуру.
